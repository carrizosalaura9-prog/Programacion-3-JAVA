Sistema de gestión de alumnos en Java

Este proyecto es un sistema sencillo para administrar registros de estudiantes, permite guardar información de cada alumno en un archivo de texto utilizando la librería de entrada y salida de Java

Funcionalidades principales

Permite registrar nuevos alumnos con un identificador único y su nombre completo, también se puede consultar la lista general de alumnos registrados en el sistema, realizar búsquedas de alumnos específicos por medio de su identificador, modificar el nombre de un alumno existente sin cambiar su identificador, eliminar alumnos del registro de forma permanente

Estructura del proyecto

La clase Alumno representa la entidad principal con sus atributos identificador y nombre, la clase AlumnoRepository administra la lectura y escritura de los datos en el archivo de texto, la clase Main contiene la interfaz de consola interactiva para el usuario

Requisitos y ejecución

Se requiere tener instalado el entorno de ejecución de Java, para iniciar la aplicación basta con compilar los archivos de código fuente y ejecutar la clase Main desde la línea de comandos
